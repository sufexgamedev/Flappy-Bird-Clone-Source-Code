# Flappy Bird Clone (Unity 2D)

Hi, My name is Abu Sufiyan Arshad and this is my first game project built using Unity and C#.  
It is a simple Flappy Bird clone where the player controls a bird and tries to pass through obstacles without crashing.

## 🎮 Features
- Smooth bird movement mechanics
- Score system
- Collision detection
- Simple and clean UI

## 🛠️ Built With
- Unity (2D)
- C#
- Visual Studio

## 🚀 Purpose
This project was created as my first step into Unity Game Engine to learn:
- Unity basics
- Game physics
- Scripting in C#
- Game loop and mechanics

## 📂 How to Play
- Tap to make the bird jump
- Avoid hitting pipes
